# translate-keyer

Helpers for [react-i18next](https://react.i18next.com/) projects translated in [Phrase](https://phrase.com/): translation keys carry descriptions for translators, missing keys are reported, and Phrase in-context editing can be switched on.

Created by [Nicholas Elliott](https://nicholasmtelliott.com) at Skyward App Company. Maintained by [@NicholasMTElliott](https://github.com/NicholasMTElliott).
